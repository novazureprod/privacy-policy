# Analyse de la vidéo de référence (images toutes les 0,1 s, 165 images, 16,5 s)

## Décor
- Bureau noir laqué (chêne noir), pool de lumière d'une lampe au-dessus à gauche.
- Objets : cappuccino (droite haute), crayon (gauche), cartes de visite (droite basse), succulente (gauche haute).
- Titre en haut à gauche : « Interactive Portfolio that you can explore » (sous-titre petit).

## Chronologie
- 0,0–2,0 s : vue fixe du livre noir fermé, titre visible, léger déplacement de caméra.
- 2,0–2,6 s : le curseur survole la couverture ; la couverture s'ouvre, la caméra se rapproche et se baisse.
- 2,7–3,4 s : double page : sommaire (gauche, crème) + cas « Every layer tells a story » (droite, photo bleue).
- 3,4–4,6 s : la caméra balaye légèrement, le livre se stabilise.
- 4,6–6,0 s : tournage d'une page ; le cas à droite passe du bleu à une mosaïque pixelisée « 86 ».
- 6,0–7,5 s : repos, curseur qui bouge.
- 7,5–8,8 s : tournage rapide, la page se décolle par le coin et s'enroule ; plusieurs feuilles défilent (« Every drop », « See beyond », « Enter new places », « The scent of stones », « MARS »). Ombres portées sur la table.
- 8,8–10,0 s : double page « DJ Zak Derdan » + « See through complexity » ; vue en plongée.
- 10,1–12,0 s : texte de cas qui apparaît en fondu (« Rooted in the golden-era deep house… »).
- 12,0–13,9 s : tournage vers « NYBLO ONE » (orange) puis « OSTREL » (horloge 6:34).
- 14,0–15,4 s : double page « OSTREL » + « NYBLO ONE », éclairage de lampe.
- 15,5–16,5 s : retour au bureau, le livre fermé et le titre réapparaissent.

## Ce qu'il faut reproduire
- Livre : couverture rigide qui s'ouvre, feuilles souples avec ombres portées.
- Pages au format 16:10 ; chaque page contient le cas, qui joue une vidéo au survol.
- Tournage : clic sur une moitié, glissement par le bord (la page se courbe et le coin se décolle), accès direct depuis le sommaire, flèches du clavier.
- Caméra : poussée vers le livre à l'ouverture, légère inclinaison vers le curseur, titre qui s'efface quand le livre est ouvert.
- Décor 3D : bureau laqué, lampe, objets modélisés.

## Limites
- Les vidéos de cas doivent être des fichiers locaux (une vidéo YouTube ne peut pas servir de texture 3D).
- Le photoréalisme exige des photos réelles (papier, cuir, bois).
